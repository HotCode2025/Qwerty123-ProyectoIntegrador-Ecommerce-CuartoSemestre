Relaciones

Una categoría y una marca tienen muchos productos

Un producto tiene stock por cada talle

Un usuario hace muchos pedidos

Un pedido tiene muchos ítems (producto + talle)

Un aviso de stock espera un producto en un talle

ajustes_tienda no se relaciona: guarda envío y recargo
